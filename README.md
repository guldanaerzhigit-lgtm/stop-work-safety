# STOP WORK Safety

Веб-приложение для регистрации остановок небезопасных работ в телекоммуникационной компании.

## Что есть в MVP
- Адаптивный интерфейс для телефона и компьютера.
- Переключение русского и казахского интерфейса.
- Регистрация опасности: объект, категория и описание.
- Журнал STOP WORK и смена статусов.
- Демонстрационные записи для проверки интерфейса.
- Основа Cloudflare Worker, D1 migration и GitHub Actions build workflow.

> Важно: текущая версия — frontend MVP с локальным состоянием браузера. Данные пока не сохраняются на сервере. Не используйте её как единственный официальный канал оповещения. Возобновление работ допускается только после реальной проверки устранения опасности и официального разрешения по процедуре компании.

## Локальный запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

## Cloudflare
1. Создайте Worker в Cloudflare.
2. Установите зависимости: `npm install`.
3. Создайте D1 database и примените `migrations/0001_init.sql`.
4. Пропишите database_id и binding в `wrangler.toml`.
5. Настройте R2 bucket для фото и вложений.
6. Настройте авторизацию и проверку ролей перед производственным запуском.
